# AI 封面与摘要工作流（Cover Workflow）

> 用途：为 Lab 作品生成**能代表它、介绍它**的卡片封面 + 一句话摘要。
> 执行者：维护 Agent（本流程对人和 AI 都可读、可复现）。
> **铁律：先读懂作品，再动手画。禁止不看说明就生成。**

## 0. 何时需要 / 何时重生成

- 作品 `thumb` 为空/null → 生成。
- 已有封面但**画面不贴产品**（用户目检不满意）→ 允许 `force=1` 重生成，但重生成前必须重新完整走一遍本流程的读说明步骤。
- 生成过一次的（`coverVersion >= 1`）不重复生成，除非上面的条件成立。

## 1. Step 1 — 读取说明源（必须先做）

按优先级取**能拿到的最全说明**，全部读一遍再继续：

1. 作品仓库的 `README.md`（main/master，经 `lib/readme.ts` / `/api/lab-readme?link=` 拉取）
2. `works.json` 里的 `body`（长描述）
3. `desc`（一句话描述）+ repo topics + 仓库首页 description + 语言/技术栈

读取后，把关键信息整理成下面这份"理解卡"：

```
产品是什么：<一句话定义>
给谁用：    <目标用户>
解决什么：  <核心问题/场景>
画面要素：  <能体现产品用途的具体形象：界面? 器械? 纸张/模板? 角色/世界? 数据?…>
视觉忌讳：  <该产品画面里不该出现的误导元素>
```

## 2. Step 2 — 产出「一句话摘要 cardSummary」

规则：
- 用**陌生用户听得懂**的话，说清"这是什么 + 解决什么"。
- 一句到两句，中文优先（站点受众），40 字以内为佳。
- 示例：手写模拟器 →「把文字渲染到打印模板上的手写效果生成器——无需 AI 生图，快而确定。」
- 禁止空话（"一个很棒的工具"）、禁止堆术语。

## 3. Step 3 — 构造画面 prompt

组合输入：`title / desc / tags / type / coverHint(如人工给) / 理解卡.画面要素`

结构（v2，按 type 定画面主体，强制让人联想到产品用途）：

```
[构图与主体：SCENE_BY_TYPE[type] + 画面要素]
[氛围与质感：现代、干净、克制的科技感，扁平插画/简洁三维风格二选一]
[禁忌：画面中不出现任何文字、单词、字母、LOGO、水印、中文]
[比例：16:9 横幅，主体居中，留白克制，适合做卡片封面]
```

SCENE_BY_TYPE（单一事实源在站点 `lib/minimax.ts`，此处为语义速记）：
- App / Product → 画出"处理的对象/产物"（如：手写模拟器 → 纸页上手写效果特写；划价系统 → 中药柜/药方单据）
- Agent / Skill → 画出"执行的任务场景"（如：叙事世界运行时 → 可演化的故事世界/角色）
- Website → 界面示意（抽象布局，不画真实截图）
- Tutorial / Article / Video → 载体 + 主题意象
- 其余类型同理：画面主体必须与产品用途强关联

## 4. Step 4 — 生成与回写

1. 调 MiniMax `image-01` 16:9（端点 `api.minimax.chat`，经 `lib/minimax.ts`）。
2. 图产物传仓库 `covers/<workId>.jpg`（Contents API PUT，base64+sha）。
3. 回写该创作者 `works.json`：`thumb = "covers/<workId>.jpg"`、`cardSummary`、`coverVersion = (旧值||0)+1`。
4. 站点侧清缓存（`invalidateLabCache`）→ 卡片/详情立即可见。

推荐入口：站点 dev 环境 `GET /api/lab-cover?workId=<id>[&force=1]`（幂等封装了上述全部步骤）。

## 5. 提交前的自检清单（交付前必答）

- [ ] 我确实读了该作品的 README/body/desc，理解卡已填
- [ ] 画面主体能让人一眼联想到**这个产品是干嘛的**（不是通用插画/装饰图）
- [ ] 画面无文字、无 LOGO、无中文（AI 生成的文字基本必错，直接禁）
- [ ] cardSummary 是"人话"，介绍的是产品而非形容词
- [ ] works.json 只新增/更新了机器字段，没动人工字段
- [ ] coverVersion 已 +1（防旧图覆盖新图）

## 6. 失败与兜底

- MiniMax 生成失败/限流 → 重试 1 次；仍失败则报告，封面保持空（卡片有克制的文字占位，不阻塞上线）。
- 图不贴产品 → 回到 Step 1 重读说明，调整理解卡再 force 重生成，禁止"盲猜着多试几张"。
